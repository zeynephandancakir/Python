### ENG

#  Core Engineering & Algorithmic Projects

A collection of lightweight Python implementations focusing on core software engineering principles, algorithm design, and applied mathematics.

##  Projects

* **[Sudoku Solver](./sudoku):** Evolutionary implementation transitioning from naive constraint check to recursive backtracking.
* **[Affine Cipher](./AffineEncryption):** Dynamic key generation and dynamic modular inverse via the Extended Euclidean Algorithm.
* **[Deadlock Simulation](./deadlock):** OOP conceptual model illustrating circular dependency and resource blocking.
* **[Euclidean Distance](./EuclidianDistance):** Mathematical utility script for spatial metric calculation.

### TR

#  Temel Mühendislik ve Algoritma Projeleri
